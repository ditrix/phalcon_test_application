## Промпт

Прочитай `AGENTS.md`, раздел 10 (Definition of done). **Шаг 7 из 8: финальная проверка и документация.** Ты работаешь как придирчивый QA, а не как автор кода.

**1. Автопроверка по чек-листу.** Пройди каждый пункт Definition of done и для каждого дай факт (команда + вывод), а не утверждение:
- `grep -rn "set_time_limit\|max_execution_time" app public cli` — пусто (кроме ini-файлов, если там нет изменений `max_execution_time`).
- `php -i | grep max_execution_time` в контейнере = 30.
- После импорта CSV через HTTP-эндпоинты (`curl`-цикл `step`) `SELECT COUNT(*) FROM requests` = 100 000.
- То же для XLSX на чистой БД (очистить `requests` и `imports` между прогонами).
- `SUM(is_duplicate)` = ожидаемое число (205); `SUM(warnings IS NOT NULL)` и разбивка по кодам warnings.
- Выборочная проверка нормализации SQL-запросами: нет телефонов не из 12 цифр, нет значений `#ERROR!`, нет email с `@@`, нет `budget_uah` вне допустимого диапазона.
- Повторный импорт того же файла создаёт **новый** `import_id`, данные первого не портит.
- Параллельный вызов `step` дважды подряд не ломает счётчики.
- Максимальное `elapsed_ms` среди всех `step`-запросов < 30 000.

**2. Таблица замеров:** файл, формат, число запросов `step`, длительность каждого (макс/сред), общее время, пик памяти.

**3. Поиск проблем.** Просмотри код на: утечки памяти в циклах; SQL-инъекции (конкатенация значений в SQL); XSS на странице; обработку ошибок и «молчаливые» падения; совместимость с PHP 7.2 (запрещённый синтаксис); использование API Phalcon, не проверенных в 3.4; лишний/мёртвый код. Составь список находок с приоритетами (критично / важно / косметика). **Критичное исправь, остальное только перечисли.**

**4. README.md** в корне (на русском): что делает проект, как запустить (`docker compose up -d --build`, `cli/migrate.php`), как проверить, структура проекта, **принятые решения** и почему (дубли `external_id` и отказ от UNIQUE, политика «ничего не отбрасывать», нормализация и коды warnings, импорт чанками через несколько запросов вместо `set_time_limit`, потоковый разбор xlsx без библиотек), таблица замеров, известные ограничения (что бы улучшил при наличии времени: очередь/воркер, UNIQUE-политика, прогресс загрузки, тесты на PHPUnit и т.д.).
